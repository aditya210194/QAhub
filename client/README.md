# QA Hub - Software Testing Education Platform

## 🚀 Tech Stack

- **Frontend:** Next.js 14
- **Styling:** CSS3, Bootstrap 5
- **Authentication:** JWT
- **API:** RESTful
- **Testing:** Jest, React Testing Library

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/qahub-client.git

# Install dependencies
npm install

# Copy environment variables
cp .env.example .env.local

# Run development server
npm run dev
